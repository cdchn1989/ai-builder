## Decisiones
- `WsEvent` se deriva de un `WsEventSchema` (Zod) en vez del tipo literal de la spec: misma forma, pero permite validar mensajes en el cliente (T-07). `timestamp` se valida como datetime ISO.
- `main`/`types` siguen apuntando a `src/index.ts` para no obligar a api/web/Docker a compilar antes de usar el paquete; `dist/` queda disponible con `npm run build -w @reservas/shared` (ignorado por git).
- Límites de los esquemas copiados literalmente de la spec; tests cubren bordes (3/100 chars, capacidad 2/50, etc.).
